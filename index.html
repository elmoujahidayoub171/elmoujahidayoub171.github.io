Port Monitoring Platform

An ETL pipeline that makes Linux network activity easier to understand. It collects system data, prepares it for analysis, and presents statistics and alerts in a Flask dashboard.

  • Python
  • Flask
  • PostgreSQL
  • Docker
  • Docker Compose
  • Linux
4dashboard KPIs
4Compose containers

The complete pipeline, from system-level collection to the dashboard, runs with Docker Compose.

Explore the architecture
  1. Collector

    Collects network and process activity on Linux with ss, lsof, and ps.

  2. Manager

    Cleans, transforms, and validates the collected data.

  3. PostgreSQL

    Stores the prepared data for querying and analysis.

  4. Analytics

    Generates statistics and alerts from the stored activity.

  5. Dashboard

    Presents four KPIs and analysis in an interactive Flask interface.
